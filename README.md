# Christmas Tree · v17.6

打开摄像头，圣诞树就站在你的房间里 —— 纯前端单文件实现，无任何依赖。

## 在线预览

GitHub Pages：<https://guozhihao33.github.io/christmas-tree-v17.6/>

> 需要 **HTTPS 或 localhost** 才能调用摄像头（GitHub Pages 本身就是 HTTPS，直接可用）。

## 玩法

1. 打开页面 → 点「开启摄像头」，浏览器弹出授权时选「允许」
2. 摄像头画面会成为场景背景：你的房间、你的人、你的桌子都在画面里
3. 一棵发光的圣诞树站在画面中央的地面上，雪在你眼前落下
4. 拖动可以绕着树转，滚轮可以拉近拉远；左下角按钮可随时关掉/重开摄像头
5. 不想开摄像头也没关系：点「先看夜景版」，就是纯星空版

**隐私**：画面只在本机 Canvas 里实时合成，不上传、不保存、不做任何识别。

## 特点

- **摄像头实拍合成**：`getUserMedia` 实时取流，镜像 + 半分辨率柔化 + 冷调色，和粒子灯光融为一体
- **纯 Canvas 2D 渲染**：手写透视投影 + 深度衰减，无 Three.js、无外部 CDN，离线也能跑
- **6800+ 针叶粒子**：分层冷杉轮廓，由内向外的体积感
- **460 颗螺旋灯带**：冷暖双色，逐颗呼吸闪烁
- **78 颗挂饰球**：金、红、冰蓝、白四色高光
- **树顶星**：六道旋转光芒 + 呼吸光晕
- **三层景深飘雪**：近景柔焦、远景细雪
- **交互**：拖动旋转（带惯性）、滚轮缩放、静止 0.9 秒后自动慢转
- **优雅降级**：无摄像头 / 拒绝授权 / 非 HTTPS → 自动回落到夜景版，不会白屏
- **自适应**：DPR 高清渲染，手机端同样适配

## 使用

```bash
# 直接打开（摄像头在 file:// 下多数浏览器会拒绝，建议起个本地服务）
python3 -m http.server 8000
# 然后访问 http://localhost:8000
```

或把 `index.html` 丢到任意 **HTTPS** 静态托管（GitHub Pages / Vercel / 对象存储）。

## 调参

`index.html` 里的 `CFG` 对象：

| 参数 | 含义 | 默认 |
| --- | --- | --- |
| `treeH` / `treeR` | 树高 / 底部半径 | 7.4 / 2.62 |
| `camDist` | 相机距离（缩放） | 12.2 |
| `centerY` | 夜景版树心高度（占屏比） | 0.525 |
| `camCenterY` | 摄像头版树心高度（更靠下，站在地面） | 0.615 |
| `spin` | 自动旋转速度 | 0.00055 |

摄像头画面的亮度/饱和度在 `drawCamera()` 里的 `brightness(.62) saturate(.9)` 处调整。
